# Proposal

## Why

El README y AGENTS.md aún contienen referencias a código Tauri/Rust que ha sido eliminado del proyecto. El proyecto ahora es exclusivamente Godot 4.8. Estas referencias obsoletas crean confusión sobre el estado actual del proyecto y su estructura.

## What Changes

- ✅ **Actualizar README.md** para reflejar que el proyecto es exclusivamente Godot 4.8
- ✅ **Eliminar referencias a Tauri/Rust** en la estructura del proyecto
- ✅ **Actualizar tabla de estado** para mostrar que Godot es el cliente principal
- ✅ **Simplificar AGENTS.md** eliminando referencias obsoletas y reduciendo el contexto
- ✅ **Actualizar rutas** para reflejar la estructura actual del proyecto Godot

## Capabilities

### New Capabilities
- **project-documentation**: Documentación clara y actualizada del proyecto Godot sin referencias obsoletas a Tauri/Rust

### Modified Capabilities
- **project-structure**: La estructura del proyecto ha cambiado - ya no tiene código Tauri/Rust como componente activo

## Impact

- **README.md**: Cambios estructurales y actualización de referencias
- **AGENTS.md**: Simplificación y actualización de reglas
- **docs/**: Referencias necesarias se actualizarán
- **No impacto en código**: Solo documentación
- **Sin breaking changes**: No hay cambios en funcionalidad, solo documentación
