# Skill: investigación del cliente DreamFus

## Fuentes locales

1. `docs/research/INDEX.md`
2. `docs/research/REFERENCES.md`
3. `docs/research/RESEARCH-METHOD.md`
4. `docs/research/AI-HANDOFF.md`

## Proceso

1. Encontrar el repositorio público.
2. Fijar rama/tag/commit.
3. Leer `LICENSE`, `NOTICE`, `README` y tests.
4. Registrar lenguaje, versión, módulo y fecha.
5. Clasificar la evidencia A/B/C/D.
6. Documentar la idea, no copiar código por defecto.
7. Comprobar si la licencia permite reutilización.
8. Crear una interfaz y tests propios para DreamFus.
9. Enlazar la investigación desde `INDEX.md`.

## Prohibiciones

- No descargar ni versionar clientes oficiales.
- No copiar assets propietarios.
- No incluir credenciales, cuentas o capturas de tráfico reales.
- No afirmar que una URL o licencia está verificada si no se comprobó.
- No convertir un comentario o README en especificación de protocolo.
