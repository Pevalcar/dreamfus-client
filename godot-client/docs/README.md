## MCP Integration

The Godot client supports MCP (Model Context Protocol) for enhanced code navigation:

1. Install Godot MCP Toolkit: `npm install -g @npgamedev/godot-mcp-server@1.1.2`
2. Open the project in Godot 4.8
3. Use MCP tools for symbol search, code tracing, and architecture queries
